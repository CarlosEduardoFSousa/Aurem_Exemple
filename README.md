# AUREN — Alta Joalheria

Site demonstrativo de uma marca fictícia de alta joalheria, criado como projeto de portfólio. A página apresenta uma coleção de joias, a história da marca e uma seção para atendimento personalizado.

## Funcionalidades

- Layout responsivo para diferentes tamanhos de tela
- Catálogo de joias com filtros por categoria
- Menu adaptado para dispositivos móveis
- Botões de consulta que direcionam para o WhatsApp
- Animações de conteúdo ao rolar a página
- Estrutura com recursos de acessibilidade

## Tecnologias

- HTML
- CSS
- JavaScript

## Como visualizar

Baixe ou clone este repositório e abra o arquivo `index.html` no navegador. Não é necessário instalar dependências.

## Estrutura do projeto

- `index.html` — conteúdo e estrutura da página
- `style.css` — estilos e layout
- `script.js` — interações e funcionalidades

## Aviso

Este projeto é fictício e foi criado apenas para fins de demonstração e portfólio. Os produtos, preços, endereço e informações de contato exibidos não são reais.
